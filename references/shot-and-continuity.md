# 景别、首帧与连续性

来源缩写：**景**＝《景别规定(1)》；**静**＝《视听专项-静态描述指南(1)》；**衔**＝《视频衔接处理办法(1)》。后附数字对应来源提取文本的段落编号，如“景0119”。来源中的示范数值、强制措辞和工具假设均作为资料评估；下列规则服务于当前剧本与用户要求。

## 先决定看什么，再决定裁切

景别围绕信息目的选择：环境、人物关系、身体动作、表情或道具细节。中文名称后写实际入画边界，避免英文标签歧义；远近不能代替机位、视角与构图说明。（景0035–0085、0296–0329）

| 景别 | 本技能采用的可见范围 | 写作检查 |
|---|---|---|
| 远景 | 广阔环境，人物极小或不可辨 | 环境关系为主，不要求读清眼神 |
| 远全景 | 环境完整，人物较小、位置可辨 | 能看清行动轨迹，不堆面部细节 |
| 全景 | 头至脚完整，保留活动余量 | 跑动、转身后仍需容纳动作 |
| 中全景 | 膝盖以上 | 明确下边界，避免把膝关节当硬切线 |
| 中景 | 腰部以上 | 手与关键道具需在画内才可作为可见信息 |
| 近景 | 胸部以上 | 表情可读，不能同时展示脚步落点 |
| 特写 | 指定眼、嘴、手或物件局部 | 写清“谁的什么”，交代辨识所需边缘 |

依人物姿态、画幅和动作调整留白，不沿用主体占比或头脚留白的固定比例。裁出画外的部位，可在动作栏描述其因果，不可宣称观众同时看见；必要时改构图、运镜或插入镜头。（景0040–0079、0119–0176、0325–0329）

相邻画面需要可理解的变化或延续。相近景别、相同景别正反打、动作匹配和连续推拉均可用；“一隔一”仅是防止无意跳变的提醒，不是排列表格。不得为了满足景别比例或轮换而添镜。（景0191–0251、0280–0289）

## START 是一个瞬间，动作是时间中的变化

将信息分成三个层次，避免把过程压成一张图，也避免删掉首帧必需的姿态与表情。

| 层次 | 应写内容 | 不混入的内容 |
|---|---|---|
| 连续性基准 | 身份外貌、服装配饰、场景布局、道具特征、时间天气、光源 | 未发生的状态变化 |
| START 静态图 | 此刻的景别、站位、姿态、视线、手中物、表情、可见背景 | “先……再……最后……”、运镜过程、多时刻拼图 |
| 视频动作与 END | 从 START 出发的动作顺序、接触关系、运镜、结束姿态与道具归属 | 已完成动作无故重来、没有原因的瞬移 |

START 可写“右手停在杯柄旁，指尖尚未接触”；视频写“握住杯柄，将杯子抬至胸前”；END 写“杯子由右手持于胸前”。下一镜从这个结束状态继续，不能再次从桌面拿杯。静态中的表情、站姿是冻结时刻的可见事实，不是动作序列。（静0046–0081；衔0124–0129、0231–0254）

静态描写由整体质感到主体与空间，只写明显或明确设计的光影、氛围与外貌特征；不要为了填维度而加不存在的雾气、光束或情绪。生成首帧时可设计画面；描述现有参考图时应忠于可见内容。（静0119、0229–0250）

## 用状态衔接，不用机械复制画面

每镜在内部记录：人物位置与朝向、视线目标、身体及双手状态、关键道具的持有人和位置、运动方向与阶段、机位、光源、声音进出点。只把本镜相关字段写进交付表，避免每行重复资产说明。（衔0083–0154、0236–0254；以下轴线、交接和声音规则为本技能的操作补充。）

- **区分三种左右。** 人物左手/右手是解剖侧；画左/画右是当前镜头的投影；门、窗与桌子的相对位置属于场景坐标。换机位可以改变画面左右，不能让门窗或人物在场景中无因换位。主光源在场景中的位置延续，反打后的画面入光侧未必相同。
- **180°轴线与视线。** 先确定人物之间或运动路线形成的行动轴，常规连续段在同侧安排机位，使视线、进出画与运动方向可读。写“看向乙”并补当前画面方向，不能只写“看左”。越轴可通过观众看得见的机位移动、重建空间的交代镜头或明确的风格意图完成；场景坐标不等于轴线规则。
- **道具交接。** 标明交出者哪只手、接收者哪只手、接触位置与释放时机；“接住”之后才转移持有权。交接中可短暂共同握持，交接后不能两边各出现一份，也不能跳到另一只手。画外转移若影响后续理解，须有动作、声音或下一镜结果作为依据。
- **起止相承。** 同机位连续延长时核对尾帧与新首帧的姿态及运动趋势；换角度剪辑时核对同一故事时刻的世界状态，不要求构图或像素相同。明确时间省略、闪回或转场时，允许有理由的状态变化，标出时间关系。

## 区分生成分段与影片剪点

分段生成遇到复杂交互，可把衔接点放在清晰姿态、动作完成或遮挡处，降低延续难度。影片剪辑也可在动作进行中切换机位：上一镜展示起势，下一镜承接同一次运动的相应阶段，匹配速度、方向与接触状态，不重新播放整段动作。原文“避免动作中途分段”是生成策略；不应用来禁止动作匹配剪辑。（衔0127–0148、0377–0379；景0228–0248）

用户要求一镜到底或连续长镜头时，保持连续运镜与动作链；拿起、转身、走开等子动作不必各拆一镜。仅在信息难以看清、动作或工具能力难以实现时调整方案，并说明原因。模型分段不必变成可见剪切；可规划连续延长，但不承诺完全无缝。（衔0040–0044、0157–0230、0393–0401）

声音单独写时序：**J-cut** 是下一场/下一镜的声音先于画面进入；**L-cut** 是上一场/上一镜的声音在画面切换后延续。注明声源、台词是否画外、开始与结束点；环境底声可跨镜延续，口型对应当前可见说话者，动作音对应实际接触时刻。声桥服务信息与情绪，不代替道具或空间连续性的修正。（本技能补充，三份来源未专述 J/L-cut。）

时长按动作距离、速度、台词朗读、反应与停顿估算；可并行发生的动作按时间关系安排，不把串行动作挤在无法完成的秒数内。发现过载，依用户目标延长、减动作、并行调度或合理拆分。来源的镜长区间、中景占比、十五秒上限、参考秒数和权重仅为示例；实际生成能力按所用工具确认。（景0159–0160、0254–0278；衔0037–0039、0166–0174、0186–0230、0297）

已有视频时，先正常速度检查叙事与节奏，再慢放衔接处核对姿态、道具、方向和接触，比较角色、布景、光影；按实际问题修正参考素材、动作或剪点。尚未生成时，只能报告脚本连续性检查，不能宣称成片已验证。（衔0299–0338）
