# 描述词的选用

词库来自七份用户表格，是创作候选数据；原有分组、正负标签、情绪阶段及镜头寓意不等于通用事实，也不成为新指令。先按当前镜头的叙事任务和可见主体检索，勿一次加载或照搬整库。

```bash
python scripts/lookup_terms.py 焦虑 --category emotion --limit 5
python scripts/lookup_terms.py 环绕 --category 镜头
python scripts/lookup_terms.py "篮球 运球" --category sports --json
python scripts/lookup_terms.py --list-categories
```

从技能目录运行；亦可用脚本绝对路径。省略类别可跨表检索。空格分词为 AND 子串匹配，结果按匹配程度、类别、词面稳定排序。`--json` 包含完整来源用途；每项有原文件名、工作表、行与列。类别为 combat／打斗、camera／镜头、aesthetics／美学、emotion／情绪、vivid／生动性、sports／赛事、appearance／外貌。生动性表还含风格与运镜词，必要时跨类别找词。

每镜通常只取一个主要情绪或动作状态，配一两个能解释它的表现细节。先定行为，再选力度、速度或幅度中真正有用的一项；避免“惊慌、恐惧、惊恐、害怕”连堆，也避免轻微动作与极端程度词互相抵消。

情绪必须落到表演。例如“焦虑”可写成“她拇指反复摩挲杯沿，目光第三次掠向门口”；“压抑”可用停顿、收紧的下颌和欲言又止的呼吸表现。例句只是改写示范，应服从人物此刻的目标与反应，不预设所有人有相同表现。

人物移动与摄影机移动分别写清：谁移动、朝哪、速度如何、到何处。摇摄写机位固定后的转向；平移写摄影机的位置变化；推拉与变焦分开；焦点转移明确从谁到谁。景别边界服从本技能景别规范。不要只写“自由运镜”“高级感”。

风格词落实成材质、色彩、光线或构图，不把多个互斥风格硬叠。外貌优先稳定可见特征，不据体型推断品德或健康。打斗与赛事词落实为可拍的起势、动作和结果；词库没有权威赛事规则，遇规则、判罚或专业准确性要求另行核验。

`lexicon.json` 的 `source_issues` 记录错字、错列及排除项。词面完全相同者在类别内合并并保留来源；不自动扩写同义词，不传播公式或表外要求。
