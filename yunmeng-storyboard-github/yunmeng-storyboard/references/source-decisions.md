## 主模板裁决

依据《通用模板V3.0》：

| 原文 | 技能处理 |
|---|---|
| §0018、0043–0047统一8K/HDR、ARRI、f/2.8、24fps | 可选美学描述与实际导出设置分开，不默认堆满摄影器材；景深须容纳叙事对象，实际像素/帧率由工具设置决定。 |
| §0018“≤30%/帧”与§0183“每秒≤30%” | 原文单位冲突且不是平台通用稳定阈值，均不作为保证。具体描述路径和速度感，查看生成结果。 |
| §0025建议空镜开场 | 按信息任务选择，可直接进入冲突或动作。 |
| §0031、0237每镜至少一个动作节点 | 人物有清楚状态和注意目标即可；不强迫静默反应镜头加手势。 |
| §0034、0226–0230对话固定正反打及仰俯权力含义 | 作为可选视听策略；双人同框/长镜头同样成立，机位含义由情境决定。 |
| §0040核心剧情节点必须对白推动 | 与画面优先原则冲突，改为核心节点需清楚可感知，可用动作、信息揭示或对白。 |
| §0149、0178起始帧必须与上镜尾帧高度相似 | 连续生成可参考尾帧；剪辑换景别或正反打时保留场景/动作逻辑，不强求像素构图相同。 |
| §0249动作必须缓起缓收 | 只在该动作真实需要时使用；惊吓、打断和突然停步允许突发变化，仍交代动因和支撑。 |
| §0255–0278导演姓名作为风格捷径 | 优先写可执行的距离、速度、调度和色彩，不用姓名替代镜头设计。 |
| §0289每镜200–400字 | 仅可作控制冗余的经验；以任务清楚、模型约束和可独立粘贴为准。 |

其余冲突见对应参考：景别隔级切换不是硬配额；静态画面可包含可见姿态；长镜头不必舒缓；情绪统一与有意声画对位都可成立；人物不必有童年创伤；不规定每30–60秒加呼吸或每3–5秒留余韵。

## 图表与词库清理

八篇思维文档的去重20张剧照/宣传图已视检，未发现额外图内教学。有些剧照与段落事件不匹配，静态图也不能证明剪辑或音乐效果，因此仅保留可支持的原理；不复制图片作为默认风格素材。静态指南的有效内嵌图为1张医院外景，用于说明色调/影调与空间对象区分。

七份词表的词语在类别内精确去重，保留来源文件、工作表、行列；疑似错字、残缺词、赛事规则或错位栏目不自动变成技能事实。详细28项来源问题存于词库 `source_issues`，检索命中疑义时看条目提示。不要凭词表里出现某技术名就假定模型支持它。

## 用户工作方式与项目边界

用户希望完整可复制的结果、真人感、人物讲话、镜头连续、无无根据的验收承诺。将这些落实到资产状态、镜头表、静态/动态分离、物件归属和证据检查。题材、对白语言、画幅和字幕仍按每次任务决定；校园制服、具体角色、茶渍和固定座位不是全局默认。

本技能可自动用于相关任务；它不会自动调用收费外部服务、生成整集视频或发布作品。当前任务授权生成的内容应继续完成，不能以本技能的流程另造重复审批。
